# RSI 다이버전스 스캐너

차트 일일이 넘기면서 "여기 다이버전스 걸렸나?" 확인하는 게 귀찮아서 만든 사이트예요.
선물 코인들을 시간봉별로 쭉 훑어서, RSI 다이버전스가 걸려 있는 종목만 모아 보여줍니다.

거래소 공개 시세만 읽어요. API 키도 없고 로그인도 없고, 내 계정 정보는 아예 건드리지 않습니다.

## 돌려보기

```bash
npm install
npm start
```

그다음 http://localhost:3000 을 열면 됩니다. 처음엔 150종목 × 4개 시간봉을 훑느라 1분쯤 걸리는데,
다 끝나기 전에도 찾은 건 바로바로 화면에 올라와요.

테스트는 `npm test`, 실제 거래소 데이터로 신호를 다시 확인해 보고 싶으면
`node tools/live-check.js 1h,4h 100` 을 돌리면 됩니다.

## 뭘 찾아주나

흔히 말하는 그 다이버전스 네 가지예요.

- **상승 일반**: 가격은 저점을 낮췄는데 RSI 저점은 오히려 올라간 경우. 떨어지는 힘이 빠지고 있다는 신호로 봅니다.
- **하락 일반**: 가격은 고점을 높였는데 RSI 고점은 낮아진 경우. 올라가는 힘이 빠지는 쪽.
- **상승 히든**: 가격 저점은 높아지는데 RSI 저점은 낮아진 경우. 상승 추세가 이어질 때 자주 나와요.
- **하락 히든**: 가격 고점은 낮아지는데 RSI 고점은 높아진 경우. 하락 추세가 이어질 때.

그리고 각 신호에 두 가지 상태가 붙어요.

- **확정**: 두 번째 피벗 뒤로 5봉이 지나서 굳은 것
- **형성 중**: 2~4봉밖에 안 지나서 아직 굳기 전인 후보. 빨리 보이는 대신 뒤집힐 수 있어요.

## 어떻게 판정하나

RSI 14에서 좌우 5봉짜리 피벗을 잡고 두 피벗을 비교합니다. 그냥 비교만 하면 가짜가 너무 많아서 몇 가지는 걸러요.

- 두 피벗을 이은 선을 그 사이 봉이 뚫고 지나갔으면 버립니다 (RSI, 가격 둘 다)
- 두 번째 피벗 뒤에 저점이나 고점이 깨졌으면 이미 끝난 신호라서 버립니다
- 피벗 간격이 5봉 미만이거나 60봉 넘는 것, RSI 차이가 1포인트도 안 되는 것, 가격 차이가 0.1% 안 되는 것도 버립니다

계산은 **마감된 봉만** 써요. 진행 중인 봉을 섞으면 RSI가 계속 흔들려서 신호가 깜빡거리거든요.
그래서 새 봉이 마감될 때만 다시 검사합니다. 1시간봉이면 매시 정각 직후에 한 번, 그 사이엔 거래소를 부르지 않아요.

## 믿어도 되나? 확인한 것들

- RSI 값을 TradingView랑 맞춰봤어요. BTC 1시간봉, ETH 4시간봉 둘 다 소수점 둘째 자리까지 똑같이 나왔습니다.
- RSI 쪽 테스트는 8개가 있어요. RSI는 손으로 계산한 값, 따로 짠 구현과 비교했고, 랜덤 시장 3000개에서 나온 신호는
  제 코드를 안 쓰고 정의만으로 다시 짠 검증기로 하나하나 확인했습니다.
- 실제 거래소 데이터(100종목 × 1h·4h)에서 나온 신호 115개도 전부 그 검증기를 통과했어요.

## 그래도 이건 알고 쓰세요

**신호가 잘 맞는지는 확인 안 했어요.** 정의대로 정확히 잡아내는지만 봤고, 이 신호를 따라가면 돈이 되는지는
백테스트를 안 해봤습니다. 다이버전스는 추세가 센 장에서 한참 어긋난 채로 계속 가기도 해서, 참고용으로만 보세요.
매수·매도 추천이 아닙니다.

**주식·원자재 계약이 섞여 있어요.** Gate 선물에는 코인 말고도 NVDA, TSLA, QQQ, 금(XAU) 같은 계약이 같이 올라와 있는데,
이걸 구분해 주는 값이 없어요. 그래서 제가 아는 티커를 `src/markets.js` 에 적어두고 기본으로 숨기고 있습니다.
새로 상장된 건 놓칠 수 있으니, 발견하면 `EXTRA_NON_CRYPTO` 환경변수에 추가해 주세요.

## RSI 다이버전스 확정 텔레그램 알림

거래대금 상위 코인을 훑다가, 다이버전스가 **확정**된 신호가 처음 나오면 텔레그램으로 한 번 알려줘요.
형성 중인 것은 뒤집힐 수 있어서 보내지 않아요. 기본은 1시간봉·4시간봉·일봉, 상승과 하락 모두예요.
일반 다이버전스 중에서 첫 번째 저점 RSI가 30 이하(하락은 첫 번째 고점이 70 이상)인 것만 보내요.
히든까지 받으려면 `DIV_ALERT_KIND=all`, 30·70 조건을 빼려면 `DIV_ALERT_ZONE_ONLY=off` 를 넣어요.
24시간 거래대금이 500만 USDT 미만인 종목은 빼요. 거래가 얇은 종목은 5분봉에서 가격이 들쭉날쭉해서
지표가 잘 안 맞고, 바로 빠져나오기도 어렵기 때문이에요.

메시지 예시 (값은 가짜예요):

```
📈 상승 다이버전스 확정 · 4시간봉
ABC/USDT (Gate 선물)

일반: 가격 저점은 낮아졌는데 RSI 저점은 높아짐 → 하락 힘이 약해짐

가격   0.4120 → 0.3985
RSI    28.4 → 41.2
첫 번째 저점  10-30 14:00 KST
두 번째 저점  11-01 10:00 KST
지금 RSI  47.3 · 현재가  0.4031
과매도권(RSI 30 이하)에서 시작

https://www.gate.io/futures/USDT/ABC_USDT
```

- 프로그램을 껐다 켜면 이미 있던 신호는 알리지 않아요. 재시작 때 한꺼번에 울리지 않게 하려고요.
- 끄려면 `DIV_ALERT=off`, 방향은 `DIV_ALERT_SIDE=bull`, 시간봉은 `DIV_ALERT_TIMEFRAMES=4h,1d` 처럼 바꿔요.
- 거래대금 기준은 `DIV_ALERT_MIN_VOLUME` 으로 바꿔요. 1000만 USDT 로 올리면 후보가 19개(상위 150개 중), 500만이면 33개쯤이에요.

## 하모닉 PRZ 화면

트레이딩뷰에서 쓰던 `하모닉 패턴 자동 탐지 · PRZ` 지표를 서버로 옮겼어요. 거래대금 상위 코인을
1시간봉·4시간봉으로 5분마다 훑어서 `/harmonic.html` 에 보여줘요.
텔레그램 알림은 기본으로 꺼져 있어요. 켜려면 `HARMONIC_TELEGRAM=on` 을 넣어요.
주문은 안 해요. 화면을 보고 DOA는 직접 켜는 용도예요.

오는 메시지는 네 가지예요. 같은 패턴에서 단계마다 한 번씩만 옵니다.

- 📍 **접근**: PRZ 상단까지 1% 안으로 내려왔어요
- 🎯 **도달**: PRZ에 닿았어요. 롱 트라이 구간
- ✅ **반등 확인**: 닿은 뒤 종가가 PRZ 위로 돌아왔어요. 지표의 매수 확인 신호랑 같고, 손절·목표가도 같이 와요
- ⚠️ **이탈**: PRZ 하단 아래로 내려갔어요. 패턴이 깨졌을 수 있으니 켜 둔 롱이 있으면 확인하세요

계산은 지표랑 똑같이 맞췄어요 (스윙 10%, 허용 오차 10%, PRZ 폭 3%). 다만 지표는 차트에 띄운 거래소 시세로,
여기는 Gate 시세로 계산해서 구간이 살짝 다를 수 있어요. 스윙 10%면 1시간봉과 4시간봉이 같은 구조를 잡는 일이 많은데,
그럴 땐 한 번만 보내요. 지금 살아 있는 PRZ는 `/api/harmonic` 에서 볼 수 있어요.

서버를 막 켰을 땐 이미 지나간 일을 다시 보내지 않아요. 도달·반등·이탈은 최근 2개 봉 안에 일어난 것만 보냅니다.

### 텔레그램 연결

1. 텔레그램에서 @BotFather 에게 `/newbot` 을 보내 봇을 만들고 토큰을 받아요
2. 만든 봇에게 아무 메시지나 한 번 보내요
3. `.env` 에 `TELEGRAM_BOT_TOKEN` 을 적고 `node tools/telegram-setup.js` 를 돌리면 채팅방 ID가 나와요
4. 그걸 `TELEGRAM_CHAT_ID` 에 적고 `node tools/telegram-setup.js test` 로 시험 메시지가 오는지 봐요
5. Render에도 같은 두 값을 Environment에 넣어요

### 알아둘 것

- **Render 무료 서버가 잠들면 알림도 멈춰요.** 15분 동안 아무도 안 들어오면 잠드는데, 그동안은 검사를 안 해요.
  UptimeRobot 같은 데서 `/api/health` 를 5분마다 불러 주면 안 잠들어요. 대신 무료 시간(한 달 750시간)을
  다른 무료 서비스들이랑 나눠 쓰니까, 다른 서비스도 계속 켜 두고 있으면 모자랄 수 있어요.
- **하모닉 패턴이 코인에서 맞는지는 검증 안 했어요.** 지표 주석에 있는 백테스트는 주식·ETF 10종목 기준이에요.
  대부분 AB=CD라서, 너무 자주 오면 `HARMONIC_NEAR_PCT` 를 줄이세요.

## 설정

다 선택이에요. 아무것도 안 넣어도 기본값으로 돕니다. (`.env.example` 참고)

- `EXCHANGE`: `gate`(기본) 또는 `binance`
- `TIMEFRAMES`: 검사할 시간봉. 기본 `15m,1h,4h,1d` (`5m`, `30m` 도 됨)
- `TOP_N`: 거래대금 상위 몇 개를 볼지. 기본 150
- `MIN_VOLUME`: 24시간 거래대금이 이 값(USDT)보다 적으면 제외. 기본 100만
- `EXTRA_NON_CRYPTO`: 비코인으로 표시할 티커를 쉼표로 추가
- `DIV_ALERT`, `DIV_ALERT_TIMEFRAMES`, `DIV_ALERT_SIDE`, `DIV_ALERT_KIND`, `DIV_ALERT_ZONE_ONLY`, `DIV_ALERT_MAX_AGE`, `DIV_ALERT_MIN_VOLUME`: 다이버전스 확정 알림 (위 참고)
- `HARMONIC_TELEGRAM`: 하모닉 PRZ 텔레그램 알림. 기본 `off`

## Render에 올리기

1. GitHub에 올립니다 (`.env`는 `.gitignore`에 들어 있어요)
2. Render에서 New + → Web Service → 레포 선택
3. Language는 Node, Build Command는 `npm install`, Start Command는 `node server.js`
4. 환경변수는 안 넣어도 돼요. Deploy 누르면 끝

올릴 때 알아둘 것:

- **바이낸스는 쓰지 마세요.** Render 무료 서버가 미국이라 지역 차단에 걸릴 수 있어요. 기본값인 Gate는 잘 됩니다.
- **무료 플랜은 15분 동안 아무도 안 들어오면 잠들어요.** 다시 깨면 메모리가 비어서 처음부터 검사해야 하고(1분쯤),
  그동안은 화면 위에 진행률이 뜹니다.
- 주소만 알면 누구나 볼 수 있는 공개 사이트예요. 대신 개인 정보는 없습니다.
- 차트 호출은 IP당 분당 30번으로 막아뒀어요. 이것만 거래소를 직접 부르거든요.

## 파일 구성

- `server.js`: 서버, 보안 헤더, API
- `src/rsi.js`: RSI랑 다이버전스 판정. 네트워크 안 쓰는 순수 함수라 테스트하기 쉬워요
- `src/scanner.js`: 시간봉별 검사 스케줄, 거래소 호출 속도 제한, 결과 보관
- `src/exchanges.js`: Gate, 바이낸스 공개 API
- `src/markets.js`: 비코인 계약 목록
- `src/harmonic.js`: 하모닉 PRZ 계산 (지표를 그대로 옮긴 순수 함수)
- `src/divAlert.js`: 다이버전스 확정 알림 (새로 확정된 것만 한 번)
- `src/harmonicWatch.js`, `src/telegram.js`: PRZ 감시와 텔레그램 발송
- `public/`: 화면
- `test/`, `tools/`: 단위 테스트, 그리고 신호를 따로 검증하는 도구

API는 `/api/status`(검사 진행 상황), `/api/divergences`(신호 목록), `/api/chart`(한 종목 차트 데이터),
`/api/health`(생존 확인) 네 개예요.
