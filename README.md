# RSI 다이버전스 스캐너

선물 코인 중에서 **RSI 다이버전스가 걸려 있는 종목**을 시간봉별로 찾아 보여주는 사이트입니다.
거래소 공개 시세만 읽습니다. API 키도, 로그인도, 계정 정보도 없습니다.

## 실행

```bash
npm install
npm start          # http://localhost:3000
npm test           # 단위 테스트 8개
node tools/live-check.js 1h,4h 100   # 실제 거래소 데이터로 신호 검증
```

처음 켜면 1분쯤 검사합니다(150종목 × 4개 시간봉). 끝나기 전에도 찾은 만큼은 화면에 보입니다.

## 무엇을 찾나

| 종류 | 가격 | RSI | 읽는 법 |
|---|---|---|---|
| 상승 일반 | 저점이 **낮아짐** | 저점이 **높아짐** | 하락 힘이 약해짐 |
| 하락 일반 | 고점이 **높아짐** | 고점이 **낮아짐** | 상승 힘이 약해짐 |
| 상승 히든 | 저점이 높아짐 | 저점이 낮아짐 | 상승 추세 지속 |
| 하락 히든 | 고점이 낮아짐 | 고점이 높아짐 | 하락 추세 지속 |

- **확정**: 두 번째 피벗 오른쪽으로 5봉이 지나 굳은 것
- **형성 중**: 오른쪽이 2~4봉만 지나 아직 굳지 않은 후보. 빠르지만 뒤집힐 수 있습니다.

### 판정 방식

RSI 14(Wilder, TradingView 와 같은 계산)에서 좌우 5봉 피벗을 잡고, 두 피벗을 비교합니다.
가짜 신호를 줄이려고 아래는 제외합니다.

- 두 피벗을 잇는 선을 **그 사이 봉이 뚫고 지나간** 것 (RSI·가격 양쪽)
- 두 번째 피벗 **이후에 저점·고점이 깨져서** 이미 끝난 것
- 피벗 간격이 5봉 미만 또는 60봉 초과, RSI 차이 1포인트 미만, 가격 차이 0.1% 미만

**마감된 봉만** 씁니다. 진행 중인 봉을 섞으면 RSI 가 계속 바뀌어 신호가 깜빡입니다.
시간봉마다 새 봉이 마감될 때만 다시 검사합니다.

### 검증한 것

- RSI 를 TradingView 값과 대조: BTC 1시간, ETH 4시간 모두 소수점 둘째 자리까지 일치
- 단위 테스트에서 RSI 를 손계산·별도 구현과 대조하고, 랜덤 시장 3000개에서 나온 신호를
  **구현 코드를 쓰지 않은 독립 검증기**로 다시 확인
- 실제 거래소 데이터 200건(100종목 × 1h·4h)에서 신호 115개 전부 통과

## 주의

- **참고용 신호입니다. 매수·매도 추천이 아닙니다.** 이 신호가 수익으로 이어지는지는 검증하지 않았습니다.
  다이버전스는 추세가 강하면 오래 어긋난 채 이어지기도 합니다.
- Gate 에는 주식·ETF·원자재 계약(NVDA, TSLA, QQQ, XAU …)이 코인과 섞여 있고 구분 필드가 없어서,
  알려진 티커를 `src/markets.js` 에 적어 두고 **기본으로 숨깁니다**. 새로 상장된 것은 놓칠 수 있으니
  발견하면 `EXTRA_NON_CRYPTO` 로 추가하세요.

## 환경변수

`.env.example` 참고. 전부 선택입니다.

| 이름 | 기본값 | 설명 |
|---|---|---|
| `EXCHANGE` | `gate` | `gate` 또는 `binance` |
| `TIMEFRAMES` | `15m,1h,4h,1d` | 검사할 시간봉 |
| `TOP_N` | `150` | 거래대금 상위 몇 개 |
| `MIN_VOLUME` | `1000000` | 24h 거래대금 하한(USDT) |
| `EXTRA_NON_CRYPTO` | 없음 | 비코인으로 표시할 티커 추가 |

## Render 배포

1. 이 폴더를 GitHub 에 올립니다 (`.env` 는 `.gitignore` 에 있습니다).
2. Render → **New +** → **Web Service** → 레포 선택
3. 설정

   | 항목 | 값 |
   |---|---|
   | Language | Node |
   | Build Command | `npm install` |
   | Start Command | `node server.js` |

4. 환경변수는 넣지 않아도 됩니다. **Deploy**.

### Render 에서 알아둘 것

- **바이낸스는 쓰지 마세요.** 무료 서버가 미국이라 막힐 수 있습니다. 기본값 Gate 는 접속이 됩니다.
- **무료 플랜은 15분 동안 접속이 없으면 잠듭니다.** 깨면 메모리가 비어서 처음부터 다시 검사합니다
  (약 1분). 그동안은 화면 위에 진행률이 보이고 찾은 만큼은 바로 나옵니다.
- 공개 사이트라 주소를 아는 사람은 누구나 볼 수 있습니다. 개인 정보는 없습니다.
- 차트 호출은 IP 당 분당 30회로 제한합니다. 이 호출만 거래소를 직접 부르기 때문입니다.

## 구조

```
server.js            Express, 보안 헤더, API
src/rsi.js           RSI·피벗·다이버전스 판정 (순수 함수)
src/scanner.js       시간봉별 스케줄, 호출 간격 제한, 결과 보관
src/exchanges.js     Gate / Binance 공개 API
src/markets.js       비코인 계약 표시
public/              화면 (index.html, app.js, chart.js, style.css)
test/                단위 테스트
tools/               독립 검증기, 실제 데이터 점검 도구
```

| API | 설명 |
|---|---|
| `GET /api/status` | 검사 진행 상황 |
| `GET /api/divergences` | 신호 목록. `tf, side, kind, status, maxAge, zone, nonCrypto, q, sort, limit` |
| `GET /api/chart?symbol=&tf=` | 한 종목의 캔들·RSI·다이버전스 |
| `GET /api/health` | 상태 확인 |
