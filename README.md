# RSI 다이버전스 스캐너

차트 일일이 넘기면서 "여기 다이버전스 걸렸나?" 확인하는 게 귀찮아서 만든 사이트예요.
선물 코인들을 시간봉별로 쭉 훑어서, RSI 다이버전스가 걸려 있는 종목만 모아 보여줍니다.

거래소 공개 시세만 읽어요. API 키도 없고 로그인도 없고, 내 계정 정보는 아예 건드리지 않습니다.

## 돌려보기

```bash
npm install
npm start
```

그다음 http://localhost:3000 을 열면 됩니다. 처음엔 150종목 × 4개 시간봉을 훑느라 1분쯤 걸리는데,
다 끝나기 전에도 찾은 건 바로바로 화면에 올라와요.

테스트는 `npm test`, 실제 거래소 데이터로 신호를 다시 확인해 보고 싶으면
`node tools/live-check.js 1h,4h 100` 을 돌리면 됩니다.

## 뭘 찾아주나

흔히 말하는 그 다이버전스 네 가지예요.

- **상승 일반**: 가격은 저점을 낮췄는데 RSI 저점은 오히려 올라간 경우. 떨어지는 힘이 빠지고 있다는 신호로 봅니다.
- **하락 일반**: 가격은 고점을 높였는데 RSI 고점은 낮아진 경우. 올라가는 힘이 빠지는 쪽.
- **상승 히든**: 가격 저점은 높아지는데 RSI 저점은 낮아진 경우. 상승 추세가 이어질 때 자주 나와요.
- **하락 히든**: 가격 고점은 낮아지는데 RSI 고점은 높아진 경우. 하락 추세가 이어질 때.

그리고 각 신호에 두 가지 상태가 붙어요.

- **확정**: 두 번째 피벗 뒤로 5봉이 지나서 굳은 것
- **형성 중**: 2~4봉밖에 안 지나서 아직 굳기 전인 후보. 빨리 보이는 대신 뒤집힐 수 있어요.

## 어떻게 판정하나

RSI 14에서 좌우 5봉짜리 피벗을 잡고 두 피벗을 비교합니다. 그냥 비교만 하면 가짜가 너무 많아서 몇 가지는 걸러요.

- 두 피벗을 이은 선을 그 사이 봉이 뚫고 지나갔으면 버립니다 (RSI, 가격 둘 다)
- 두 번째 피벗 뒤에 저점이나 고점이 깨졌으면 이미 끝난 신호라서 버립니다
- 피벗 간격이 5봉 미만이거나 60봉 넘는 것, RSI 차이가 1포인트도 안 되는 것, 가격 차이가 0.1% 안 되는 것도 버립니다

계산은 **마감된 봉만** 써요. 진행 중인 봉을 섞으면 RSI가 계속 흔들려서 신호가 깜빡거리거든요.
그래서 새 봉이 마감될 때만 다시 검사합니다. 1시간봉이면 매시 정각 직후에 한 번, 그 사이엔 거래소를 부르지 않아요.

## 믿어도 되나? 확인한 것들

- RSI 값을 TradingView랑 맞춰봤어요. BTC 1시간봉, ETH 4시간봉 둘 다 소수점 둘째 자리까지 똑같이 나왔습니다.
- 테스트 8개가 있어요. RSI는 손으로 계산한 값, 따로 짠 구현과 비교했고, 랜덤 시장 3000개에서 나온 신호는
  제 코드를 안 쓰고 정의만으로 다시 짠 검증기로 하나하나 확인했습니다.
- 실제 거래소 데이터(100종목 × 1h·4h)에서 나온 신호 115개도 전부 그 검증기를 통과했어요.

## 그래도 이건 알고 쓰세요

**신호가 잘 맞는지는 확인 안 했어요.** 정의대로 정확히 잡아내는지만 봤고, 이 신호를 따라가면 돈이 되는지는
백테스트를 안 해봤습니다. 다이버전스는 추세가 센 장에서 한참 어긋난 채로 계속 가기도 해서, 참고용으로만 보세요.
매수·매도 추천이 아닙니다.

**주식·원자재 계약이 섞여 있어요.** Gate 선물에는 코인 말고도 NVDA, TSLA, QQQ, 금(XAU) 같은 계약이 같이 올라와 있는데,
이걸 구분해 주는 값이 없어요. 그래서 제가 아는 티커를 `src/markets.js` 에 적어두고 기본으로 숨기고 있습니다.
새로 상장된 건 놓칠 수 있으니, 발견하면 `EXTRA_NON_CRYPTO` 환경변수에 추가해 주세요.

## 설정

다 선택이에요. 아무것도 안 넣어도 기본값으로 돕니다. (`.env.example` 참고)

- `EXCHANGE`: `gate`(기본) 또는 `binance`
- `TIMEFRAMES`: 검사할 시간봉. 기본 `15m,1h,4h,1d` (`5m`, `30m` 도 됨)
- `TOP_N`: 거래대금 상위 몇 개를 볼지. 기본 150
- `MIN_VOLUME`: 24시간 거래대금이 이 값(USDT)보다 적으면 제외. 기본 100만
- `EXTRA_NON_CRYPTO`: 비코인으로 표시할 티커를 쉼표로 추가

## Render에 올리기

1. GitHub에 올립니다 (`.env`는 `.gitignore`에 들어 있어요)
2. Render에서 New + → Web Service → 레포 선택
3. Language는 Node, Build Command는 `npm install`, Start Command는 `node server.js`
4. 환경변수는 안 넣어도 돼요. Deploy 누르면 끝

올릴 때 알아둘 것:

- **바이낸스는 쓰지 마세요.** Render 무료 서버가 미국이라 지역 차단에 걸릴 수 있어요. 기본값인 Gate는 잘 됩니다.
- **무료 플랜은 15분 동안 아무도 안 들어오면 잠들어요.** 다시 깨면 메모리가 비어서 처음부터 검사해야 하고(1분쯤),
  그동안은 화면 위에 진행률이 뜹니다.
- 주소만 알면 누구나 볼 수 있는 공개 사이트예요. 대신 개인 정보는 없습니다.
- 차트 호출은 IP당 분당 30번으로 막아뒀어요. 이것만 거래소를 직접 부르거든요.

## 파일 구성

- `server.js`: 서버, 보안 헤더, API
- `src/rsi.js`: RSI랑 다이버전스 판정. 네트워크 안 쓰는 순수 함수라 테스트하기 쉬워요
- `src/scanner.js`: 시간봉별 검사 스케줄, 거래소 호출 속도 제한, 결과 보관
- `src/exchanges.js`: Gate, 바이낸스 공개 API
- `src/markets.js`: 비코인 계약 목록
- `public/`: 화면
- `test/`, `tools/`: 단위 테스트, 그리고 신호를 따로 검증하는 도구

API는 `/api/status`(검사 진행 상황), `/api/divergences`(신호 목록), `/api/chart`(한 종목 차트 데이터),
`/api/health`(생존 확인) 네 개예요.
